# 写作规则

将给定材料整理成可以独立阅读的图文讲义。遵循用户指定的语言、范围与用途；以下为默认要求。

## 正文

1. **自包含。** 直接解释概念、理由与关系，读者无需查看原材料。避免“原课件指出”“如前面所说”“后续章节会讲”等依赖外部上下文的表述。必要背景在当前位置简要补足。
2. **简明而完整。** 压缩重复表达，不压缩学习所需的信息。保留关键定义、因果关系、区别、条件、例外和承担教学作用的例子。公式需解释变量、单位、成立条件及问题的起止点；算例保留设置、关键计算和结论，不能只留下公式或“例如”一句话。可以补充可靠的必要背景，不得编造事实、数据或出处；关键歧义先核实。
3. **首次出现的术语写全称。** 使用中文术语或缩写时，在整份正文首次出现处附完整名称，例如“往返时间（Round-Trip Time，RTT）”；后文用中文或缩写即可。不要为本来不是缩写的名称杜撰展开形式。各章分批写作时沿用已有术语记录。
4. **用段落解释，用结构突出重点。** 因果、过程、推导和条件用自然语言段落展开；具有共同维度的对象用表格比较，操作顺序可以列步骤。表格前交代比较对象，每格保持简短，表后补充关键结论或边界；不要把同一内容完整重复成段落和表格。适当加小标题、加粗核心结论，避免满页粗体或把 slides 的项目符号直接搬过来。

## 内容覆盖

每章写作前，把材料中的概念、机制、条件、公式、关键例子和易错点列成简短清单，保存在内容目录的 `.work/coverage.md`，记录来源位置与对应正文。按实际内容列项，不要求每节凑齐固定类别。参考旧讲义时也要回到原材料核对，不能默认旧稿无误。

写完先检查覆盖，再精简措辞。每项标明已解释、合并到哪里，或为何省略；重复动画和装饰可以省略，用来区分概念的算例、反例与限制条件不能悄悄消失。新增解释和自拟算例另记来源或推导依据，不冒充原材料事实。

最后从读者角度检查：能否解释机制、区分易混概念，并在适用时独立完成代表性计算？如果只能复述结论，就补上缺失的推理、条件或例子。覆盖清单留在工作文件中，正文仍保持自然阅读，不附自评话术。

## 图片与来源

选用能帮助理解的原图，保留必要标注，裁去无关装饰。正文解释图中关系，图注说明读者应观察什么，避免“见原图”或只写页码。检查图片清晰度以及图中文字、符号与正文的一致性。

来源、页码映射和新增参考资料集中记录于 `SOURCES.md`，不把溯源话术写入学习正文。需要展示的原材料版权声明，使用稿件开头的 `<!-- folio:copyright 实际声明 -->`，由编译器放入灰色页脚；不要编造权利人、年份或许可。保留必要的署名与许可信息，不因裁图或改写抹去应保留的信息。

## Markdown 约定

一个 `#` 表示文档标题；每个 `##` 开始一页；`###` 表示页内小标题。长页可以滚动，按知识主线分页，不按屏幕字数强行拆分。

图片使用相对稿件的本地路径，独立成段；可选 title 作为图注：

```markdown
# 文档标题

## 一个完整主题

直接进入解释正文。

![图片的文字描述](assets/figure.png "帮助理解图意的说明。")

### 页内小标题

继续展开相关细节。
```

使用编译器支持的 Markdown，不嵌入原始 HTML 或远程图片。数学表达式使用 `$...$` 行内公式或单独成段的 `$$...$$` 独立公式，由 KaTeX 排版；不要把公式放在反引号中。解释变量、单位、假设和适用范围，不要只放一个公式让读者猜。

除可选版权声明外，文件从标题开始，不写“以下是整理结果”等对话引言。交付前逐项检查：独立可读、细节和条件齐全、术语首次写全、表达形式合适、图文一致、路径可用、来源有记录。
